## 截图测试执行前提

20 张中文平台截图测试需要以下条件：

- 至少 20 张可用于测试的中文平台截图。
- 可用 MySQL 数据库，并已执行 `src/main/resources/db/schema.sql`。
- 可用 Aliyun OSS 私有 Bucket 配置。
- 可用 Gemini API Key。
- 应用能够通过 `/corpus/upload` 或 `/api/v1/corpus/upload` 完整访问上传链路。

当前阻塞：仓库内未发现 `.png`、`.jpg`、`.jpeg` 或 `.webp` 截图样本，因此不能真实执行“至少 20 张中文平台截图测试”，也不能据此填写成功样例和失败样例。

## 建议测试集构成

建议 20 张截图覆盖以下类型：

| 类型 | 数量 | 目的 |
| --- | ---: | --- |
| 小红书评论截图 | 4 | 验证平台识别、评论提取、标签生成 |
| 微博评论截图 | 4 | 验证短文本、多评论和上下文提取 |
| 知乎回答或评论截图 | 3 | 验证长文本和上下文边界 |
| B站评论截图 | 3 | 验证弹幕式/楼中楼式评论提取表现 |
| 微信/公众号/聊天式截图 | 3 | 验证非标准评论布局 |
| 低清晰度或遮挡截图 | 2 | 验证失败路径和错误记录 |
| 重复截图 | 1 | 验证 `image_hash` 去重 |
